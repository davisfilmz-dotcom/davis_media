# Davis Media

A multi-page business website for Davis Media featuring editing, live streaming, cinematography, a photo gallery, and a browser-based simple photo editor.

## Pages

- `index.html` — Home
- `services.html` — Services
- `gallery.html` — Gallery and photo posting
- `editor.html` — Simple image editor
- `about.html` — Contact information

## Run locally

Open `index.html` directly or run a simple local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
